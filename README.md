# Vyft Product - VEzcustody

## Overview
VEzcustody is a custody solution product. This workspace contains smart contracts, build scripts, and tests.

## Structure
- `contracts/` - Solidity smart contracts
- `scripts/` - Build/deployment scripts
- `test/` - Test files

## Current Focus
- `contracts/EACAggregatorProxy.sol` - Chainlink-style aggregator proxy contract (currently open)
- `slurabsd/` - UEFI boot payload (WHESERE.EFI + slurabsd.bin)

## Build
```bash
npm run build
```

## Test
```bash
npm test
```
